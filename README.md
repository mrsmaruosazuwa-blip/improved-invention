## Next.js Project with Vercel Analytics

This is a [Next.js](https://nextjs.org) project configured with [Vercel Web Analytics](https://vercel.com/docs/analytics).

### Getting Started

First, install dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

### Building for Production

```bash
npm run build
npm start
```

### Vercel Analytics

This project is configured with Vercel Web Analytics. The `<Analytics />` component is integrated in `app/layout.tsx` following the official Vercel documentation.

To enable analytics:
1. Deploy this project to Vercel
2. Navigate to your project's Analytics section in the Vercel dashboard
3. Click "Enable" to activate Web Analytics

Once enabled, you'll be able to track page views and visitor analytics in your Vercel dashboard.
